Listening test: admin

Sign in

The admin token is in the file admin_token of the data directory (created with mode 600 on the first start).

Status

Every code ever issued counts, by invite or registration, disabled and withdrawn ones included (addendum §7.1: 40, plus 3 pilot codes: 43 from before the pilot). When the cap is reached, no invite code is created and the page offers no registration.

Stimulus package

Place lt_data.json (or lt_data.js) and stimuli/ in <data dir>/package/, then import. The key stays in <data dir>/private/; the server never reads it and does not start while the package folder holds a key file.

Consent text

      
The filled mvc/mos/consent_template_v1.html (Vietnamese and English in one HTML fragment), saved as consent_v1.html in the data directory and shown to raters as it is. A text that still holds a placeholder ([CONTACT_NAME], [CONTACT_EMAIL], [ETHICS_NOTE], [RETENTION_DATE]), a script, an event-handler attribute, a frame or a form is refused; inline styles are not applied (the page allows only its own style sheet).
